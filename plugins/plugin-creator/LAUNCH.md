  demand data and a no-plugin baseline. Ten real plugins built with it."
- Audience: Claude Code power users and plugin authors.
- Channels:
  - r/ClaudeCode and r/ClaudeAI (show the 10 plugins as proof, one post).
  - Show HN: "Show HN: I built 10 Claude plugins in a day with a plugin that

    claude-plugins.dev, claudepluginhub.com, buildwithclaude.com.
