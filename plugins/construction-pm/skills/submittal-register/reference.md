## Categories

- Action: needs the reviewer's approval before fabrication or install
  (product data, shop drawings, samples, mockups).
- Informational: for the record, no approval action (qualifications,
  certificates, test and inspection reports, plans, field reports).
- Closeout: at or before Substantial Completion (O&M data, warranties,
  extra stock, record documents, final keying).

The spec article title decides first ("ACTION SUBMITTALS"). Older specs use a
single "SUBMITTALS" article; then the type decides.

## Types used by the script

Product Data, Shop Drawing (includes schedules, wiring diagrams, layouts),
Sample, Mockup, Qualification, Certificate, Test/Inspection Report,
Plan/Procedure, Warranty, O&M Data, Extra Stock, Closeout Document, Other.

## Register columns

Submittal No, Spec Section, Section Title, Spec Ref, Item, Type, Category,
Description, Reviewer, Need Date, Need Basis, Lead Weeks, Lead Source,
Submit By, Working, Status, Ball In Court, Flags, Source.

Reviewer defaults to Architect (Architect / MEP Engineer for Divisions
21-28). Change it if the project's Division 01 says otherwise.
